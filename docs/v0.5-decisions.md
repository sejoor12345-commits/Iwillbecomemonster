## 1. 슈퍼세트 입력 (로드맵 v0.5) — ✅ (가)로 결정, v0.5-f에서 만듦
메모로는 `Cable push down/Overhead triceps extension: 35*10/12*2`처럼 적고 있어. 앱에서 어떻게 할지 골라 줘.
- **(가) 묶어서 보여 주기만** (추천): 종목 카드에 "다음 종목과 슈퍼세트" 버튼. 묶인 두 카드가 붙어 보이고, A 세트를 끝내면 B 카드가 펼쳐져. 휴식 타이머는 B까지 끝난 뒤부터. 메모 내보내기는 지금처럼 **두 줄**로 (노트북이 그대로 읽음).
- (나) (가) + 메모도 `A/B` 한 줄로 내보내기: 노트북의 슈퍼세트 읽기와 맞지만, 두 종목의 세트 수나 무게가 다르면 한 줄로 못 적어.
- (다) 아직 안 함.

## 2. 음식 DB 연동 — FatSecret은 안 하기로 결정 → 식약처 식품영양성분 DB로 (공공데이터포털 키 필요)
지금은 FatSecret 화면을 보고 숫자를 옮겨 적고 있어. 앱 안에서 음식을 검색해서 넣으려면:
- FatSecret Platform API 가입 → 키 발급이 필요해 (무료 등급의 조건 · 출처 표기 의무는 가입할 때 확인 필요).
- 키를 앱(폰)에 넣으면 누구나 볼 수 있어서, **Supabase Edge Function**(서버 쪽 작은 함수)에 숨겨 두고 앱은 그 함수를 부르는 구조가 돼. 이건 지금 연결된 Supabase로 만들 수 있어.
- 정할 것: 할지 말지, 그리고 한다면 키 발급(네가 가입해야 함).
- 참고: 오늘 넣은 "최근 먹은 것 · 전날 복사"로 반복되는 식단은 이미 꽤 줄었을 거야. 써 보고 그래도 귀찮으면 그때 해도 늦지 않아.

## 5. 메모의 "Incline bench press"는 어느 쪽? — ✅ 바벨로 결정 (지금 그대로, 코드 변경 없음)
- 예전(7일차)에 "메모에 적은 Incline bench press = 스미스"로 정해서 Smith IBP로 바꿨었어.
- 이번 사전에서는 정식 이름 **Incline bench press = 바벨(예전 Free IBP)**, 스미스는 **Smith incline bench press**야.
- 그래서 앞으로 메모를 가져올 때 `Incline bench press`라고 적힌 줄은 **바벨** 기록으로 들어가. 앱에 이미 있는 기록은 그대로 맞게 들어가 있어 (예전에 Smith IBP로 바꿔 둔 덕분).
- 정할 것: 앞으로 메모에서 스미스는 `Smith IBP`(또는 정식 이름)로 적기로 하면 지금 그대로 두면 되고, 예전처럼 `Incline bench press`라고 적을 거면 "메모에서만 스미스로 읽기"를 넣을게.

## 6. 검토 에이전트가 찾은 것 (v0.5-d에서 고침)
- 옛 백업을 복원하면 옛 이름이 그대로 들어가던 것 → 복원할 때도 정식 이름으로
- 이름을 바꾸다 한 운동 안에 같은 종목이 둘 생기는 경우 (예: SLL + Lateral raise) → 세트를 하나로 합침
- 사전에 들어가서 없앤 "내 종목"이 Supabase에 남던 것 → 지움
- "최근 먹은 것"에 미리 적은(미래) 식단이 섞이던 것 → 지난 식단만
- 최근 음식을 누르면 음식 칸에 적던 글자가 지워지던 것 → 그대로 남음
