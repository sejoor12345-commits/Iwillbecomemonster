# 학습 기록 (노션)

목적: 사용자가 **자기 성장(progression)을 계속 볼 수 있게** 매 세션을 같은 모양으로 기록한다.

## 기록할 곳 (2곳)

| 페이지 | ID | 무엇을 |
|---|---|---|
| 「헬스 기록 분석기 + 파이썬 학습 기록」 | `3ebdc76f1b9f8103aa94de1649af40e0` | 그날의 자세한 기록 — 맨 아래에 `# N일차 (YYYY-MM-DD) — 한 줄 제목` 섹션 추가 |
| 「코딩실력 늘리기」 | `3e9dc76f1b9f81fea51ac091e6a9b95d` | 큰 흐름만 1~2줄 — "10. 복학 전까지의 흐름 → 단계 2" 진행 줄, "11. 체크리스트" 항목 옆 🟡 증거 |

## 순서

1. 첫 페이지를 `notion-fetch`로 읽어서 **마지막 N일차 번호**와 직전 "다음에 할 것"을 확인한다.
2. 직전 "다음에 할 것" 중 오늘 끝낸 항목은 `[x]`로 바꾼다 (`update_content`).
3. 맨 아래에 새 N일차 섹션을 추가한다 (`insert_content`, position end). 아래 틀을 따른다.
4. 「코딩실력 늘리기」에 진행 줄 / 체크리스트 증거를 짧게 추가한다 (`update_content`, 기존 문장 뒤에 이어 붙이기). 기존 내용은 지우지 않는다.
5. 사용자에게 페이지 링크와 "무엇을 적었는지"를 3~5줄로 알려 준다.

## N일차 섹션 틀

```
---
# N일차 (YYYY-MM-DD) — 한 줄 제목
## 1. 만든 것 / 정리한 것
## 2. 내가 정한 것          ← 사용자가 직접 내린 결정과 그 이유 (제일 중요)
## 3. 만난 문제             ← 무엇이 안 됐고, 원인과 해결
## 4. 코드 읽기             ← 무엇을 읽었나, 문제 결과(✅/반만/틀림), 이해도(사용자가 말한 %)
### 배운 것                ← JS↔Python 짝 맞추기 표 등
### 내가 한 좋은 질문
### 헷갈렸던 곳 (복습 1순위)
### 느낀 점                 ← 사용자가 한 말을 그대로 인용
## 5. 다음에 할 것          ← 체크박스 [ ]
```
그날 해당 없는 칸은 뺀다.

## 원칙

- 사용자가 **직접 정한 것**과 **자기 말로 한 느낌**을 꼭 남긴다 — 성장 기록의 핵심이다.
- 틀린 문제도 숨기지 않는다. "반만 맞음 → 무엇이 달랐나"를 적어야 복습이 된다.
- 개인정보(이메일 등)는 적지 않는다.
- 쓰기 전에 항상 fetch로 현재 내용을 확인하고, 기존 내용은 덮어쓰지 않는다 (`replace_content` 금지).
