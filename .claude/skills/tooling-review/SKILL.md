# 도구 검토 (수동 실행 전용)

## 근거로 볼 것 (먼저 읽기)
1. `git log --oneline -30` — 최근에 무엇을 반복해서 했나 (같은 종류의 수작업 · 고침이 되풀이되는 곳)
2. `README.md`의 단계 계획(로드맵) — 앞으로 할 일
3. `CLAUDE.md` — 구조와 작업 방식
4. `.claude/skills/` — 이미 있는 skill (겹치는 추천 금지)

## 판단 기준
- 작업 효율을 높일 방법을 폭넓게 본다: skill, MCP, hook, 외부 도구 · 라이브러리, 작업 방식 개선.
- 추천은 근거(커밋 · 로드맵에서 실제로 반복되거나 곧 필요해지는 일)가 있을 때만.
- 뚜렷한 근거가 없으면 **"지금은 추가할 필요 없음"이 정상적인 답**이다. 억지로 채우지 않는다.
- 이미 거절된 제안(대화 · CLAUDE.md에 남은 것)은 다시 꺼내지 않는다.

## 환경 제약 (Claude Code 웹 · 클라우드)
- **plugin은 로드되지 않으므로 추천하지 않는다.**
- 로컬 MCP는 저장소의 `.mcp.json`으로 추가한다. 네트워크 제한(프록시 · 허용 도메인) 때문에 실패할 수 있다는 점을 추천에 함께 적는다.
- 추천만 한다. 파일을 만들거나 설정을 바꾸지 않고, 사용자의 동의를 받은 뒤에 추가한다.

## 출력
한국어 반말, 짧게. 추천은 **최대 3개**, 아래 표 하나로:

| 추천 | 왜 필요한지 (근거) | 추가했을 때 달라지는 점 | 비용 · 단점 |
|---|---|---|---|

추천이 없으면 표 대신 "지금은 추가할 필요 없음"과 이유 한두 줄.
